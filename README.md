### 1. Project Setup

Run the following command in the project root directory:
    ```bash
    docker compose up --build
    ```
### 2. Open the app

Once all 5 containers are running, open your browser and go to:
    ```
    localhost:3000
    ```

### 3. Stopping

To stop the running contianers use:
    ```
    docker compose down
    ```
or
    ```
    ctrl + c 
    ```
